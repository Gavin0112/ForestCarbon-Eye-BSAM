# Main model and training

The paper's main predictor is `MSEFilm`. Its active model source is [mse_film_model.py](../experiments/agbd_lite/mse_film_main_20261022/mse_film_model.py), with the [capacity adapter](../experiments/agbd_lite/n5_capacity_control/n5_model.py). The training update is implemented by [bsam_step.py](../experiments/agbd_lite/mse_film_bsam_20261023/bsam_step.py) and the [paired training loop](../experiments/agbd_lite/bsam_fair_compute_review02_20261030/run_fair.py). The exact historical source paths remain intact so the frozen source-hash checks can identify them.

The main full-source experiment used the [Review-12 training entry](../experiments/agbd_lite/bsam_long_budget_review12_20261031/run_review12.py). `protocol/` contains copies of its frozen protocol and BSAM configuration; `results/` contains the corresponding aggregate Test records. Three seeds each have a Plain MSE and BSAM Validation-selected checkpoint in `weights/` under the [checkpoint terms](../MODEL_WEIGHTS_TERMS.md). The filename identifies the experiment, seed and training mode. Their epochs, Test metrics and original checkpoint SHA-256 values are in the [Review-12 metric record](results/REVIEW12_TEST_METRICS.json), and `weights_index.csv` maps each file to that record.

`weights/mse_film_E7.pt` is the earlier MSE-FiLM E7 comparator discussed in the paper; its [Test metric record](results/MSE_FILM_E7_TEST_METRICS.json) identifies the checkpoint hash. It is a separate comparator, not one of the six paired Review-12 checkpoints.

The later Review-12 resume delivery retains the same six best checkpoints byte for byte. Its extra training epochs produced no replacement Test checkpoint, so those files are not duplicated here. The included binaries match their indexed historical hashes and are subject to the [checkpoint terms](../MODEL_WEIGHTS_TERMS.md). The original training scripts require upstream NicoNet and external preprocessing caches described in the [reproduction notes](../docs/reproduction.md).

# Data availability and attribution

The project used [AGBD-Lite version 1](https://doi.org/10.5281/zenodo.18485030), created by Ghjulia Sialelli, Linus Scheibenreif, Jan Dirk Wegner and Konrad Schindler as a subset of the original AGBD dataset. Its [dataset card](https://huggingface.co/datasets/prs-eth/AGBD-Lite) documents access, schema and CC BY-NC 4.0 terms. The creators request citation of the dataset **and** [the original AGBD publication](https://doi.org/10.5194/isprs-annals-X-G-2025-829-2025), whose authors are Ghjulia Sialelli, Torben Peters, Jan Dirk Wegner and Konrad Schindler. This project claims no role in creating or releasing AGBD-Lite.

No dataset H5, GEDI label array, upstream satellite tile, preprocessed cache, or row-level prediction containing copied labels is included. The Data Availability section of *Footprint-Level Above-Ground Biomass Density Estimation via Multisource Fusion and Balanced Sharpness-Aware Training* points to the official Zenodo release and dataset card. The expected data directory layout and remaining cache dependencies are documented in [`data/README.md`](../data/README.md).

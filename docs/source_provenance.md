# Source and archive provenance

The original experimental archives are the authoritative handoff for Review-12, Review-13, S2-only, and extended Validation results. Review-12, Review-13 and the later Review-12 continuation came from the same server-side project; archive separation does not indicate separate servers. This repository includes selected source, configuration and aggregate-metric files. Nineteen paper-related checkpoints are included under the [checkpoint terms](../MODEL_WEIGHTS_TERMS.md). Original archives, other exploratory/intermediate checkpoints, row-level prediction CSVs and data are not distributed here.

Review-12's frozen source-hash map was checked against the included `run_fair.py`, BSAM configuration and update code, `run_mse_film.py`, and `mse_film_model.py`; all five SHA-256 values match. The 18 included Review-12, Review-13 and S2-only checkpoints match the SHA-256 values in their archived Test metric records; the included E7 comparator matches its separate metric record. The later resume delivery's six best weights are byte-identical to the six Review-12 weights and are not repeated. Review-13's M1–M6 metric JSON and sanitized M0 reuse summary derive from the original handoff. The provided six-arm runner is identified as reconstructed because the delivered Review-13 archive lacks a byte-identical copy of its training entry; this says nothing about whether the script still exists on the original server. Aggregate records for the E7 comparator, earlier equal-time check and extended Validation are included without row-level labels.

The frozen protocol and aggregate metric records retain source, checkpoint and prediction hashes needed to check the published claims. No personal username, private filesystem path or server path is needed to follow the published aggregate results.
